# SEMEO STORE — GitHub Pages

Static e-commerce demo for GitHub Pages. No server or database required.

## Upload
Upload the entire contents of this folder to the root of the GitHub Pages repository. Keep the `assets` folder and all HTML/CSS/JS files together.

## Important
The site uses the supplied product images and hero video. The brand header is text-based (`SEMEO`) so it works without an external logo file; replace the `.brand` text with the final logo image later if desired.
